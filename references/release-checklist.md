# Release gates

## Ownership and dependencies
- This package contains original instructions, examples and tests plus a separately licensed Three.js distribution. It contains no copied traffic application source, assets, screenshots, data or transcripts.
- A private reference project's lack of a LICENSE is not open-source permission. Get a licensing decision before copying any of its implementation or images. User authorization to publish a new skill does not resolve every third-party right.
- Preserve upstream copyright/license notices for every redistributed dependency. Check transitive obligations when adding a build system. Three.js 0.187.0 is MIT; optional reference-stack Vite 8.3.8 is MIT and AI SDK 7.0.179 is Apache-2.0. Vite and AI SDK are NOT required or bundled here.
- Keep generated sample data distinct from real data. Verify rights in user-supplied documents, textures, fonts, images and code. Do not assert an indemnity or a universal legal conclusion.

## Publication hygiene
- Review the complete file manifest, not only SKILL.md. Exclude secrets, credentials, .env, provider state, private identifiers, user data, logs, raw conversations and unapproved images.
- Run model tests; inspect browser/GPU checks; record unknowns. Do not label pending work passed.
- Complete README, install instructions, dependency notices, source/limitations and screenshot metadata. Replace screenshot placeholders only with real cleared captures.
- Confirm the intended repository, visibility, branch and release contents with the authorized publishing operator. This phase does not create a repo, push a commit or post on social media.
- Before any post: draft for human review; no unverified universality, production-readiness, domain-accuracy, benchmark, performance or model-comparison claims.
